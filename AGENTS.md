# Project conventions

German interface text and generated examples use gender-inclusive language. Use the colon for people, such as Leser:innen, Kund:innen and Nutzer:innen, or a suitable neutral term. Preserve verbatim source fragments.

Describe what a control, section or output does. Avoid generic slogans, empty metaphors, self-praise and formulas such as “Aus X wird Y” or “Ideen greifbar machen”. Creative headlines must refer to the actual subject.

Do not describe saved examples as live generation. Keep unavailable model functions visibly unavailable. Interactive-looking controls must have an implemented action.

Keep credentials and local project state out of source control. Preserve the existing Site identity and audience when editing the hosted application.
